## Opis
Klikljiv prototip spletne aplikacije s tremi pogledi (administrator, učitelj, učenec), narejen samo s HTML in CSS (brez JavaScripta). Odprite `index.html` v brskalniku. Na prijavni strani izberite vlogo.

## Struktura
```
index.html                 prototip aplikacije (vse strani)
css/style.css              oblikovanje
docs/dokumentacija-word/   specifikacija, ER diagram, tehnična dokumentacija, navodila,
                           testni primeri, poročila (tedenska, dnevna, zaključno)
docs/wireframe/            skice zaslonov, ER diagram, arhitektura (PNG)
.github/                   predloge za napake in vlečne zahtevke
```

## Javna objava (GitHub Pages)
Settings → Pages → Source: *Deploy from a branch* → veja `main`, mapa `/ (root)`. Stran je nato dostopna na `https://UPORABNIK.github.io/IME-REPOZITORIJA/`.

## Omejitve
HTML in CSS ne omogočata shranjevanja podatkov, preverjanja gesel ali nalaganja datotek. Podatki v prototipu so vnaprej vpisani, gumbi za shranjevanje so demonstracijski.
